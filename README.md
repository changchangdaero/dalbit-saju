# 달빛사주

생년월일과 출생 정보를 바탕으로 오행의 흐름과 성향, 관계, 일에 관한 이야기를 보여 주는 감성 사주 웹사이트입니다.

## 주요 기능

- 이름, 생년월일, 출생시간, 성별 입력
- 입력값에 따라 일관된 사주 이야기 생성
- 목·화·토·금·수 오행의 상대적 균형 시각화
- 성향, 관계, 일과 방향에 대한 해석
- 오늘의 조언, 행운의 색과 숫자 제공
- 모바일과 데스크톱 반응형 화면
- 입력 정보는 저장하거나 외부로 전송하지 않음

현재 버전은 API 키 없이 체험할 수 있는 MVP입니다. 결과는 브라우저에서 로컬 규칙으로 생성되며, 실제 생성형 AI나 만세력 계산 API는 연결되어 있지 않습니다.

## 실행 방법

Node.js가 설치된 환경에서 다음 명령을 실행합니다.

```bash
npm install
npm run dev
```

터미널에 표시되는 로컬 주소를 브라우저에서 열면 됩니다. 기본 주소는 보통 `http://localhost:5173`입니다.

## 검증

```bash
npm run lint
npm run build
```

프로덕션 빌드 결과물은 `dist` 디렉터리에 생성됩니다.

## 기술 구성

- React
- Vite
- 순수 CSS 반응형 디자인
- ESLint

## 실제 서비스로 확장하려면

1. 만세력 계산 라이브러리 또는 검증된 사주 API를 연결합니다.
2. 서버에서 생성형 AI 모델을 호출해 계산된 명식을 자연어 해석으로 변환합니다.
3. 요청 횟수 제한, 오류 처리, 개인정보 처리방침을 추가합니다.
4. 결과 공유 이미지와 소셜 로그인, 결제 기능 등을 필요에 따라 확장합니다.

> 사주 결과는 오락과 자기 성찰을 위한 콘텐츠이며, 의료·법률·재정 등 중요한 결정의 근거로 사용해서는 안 됩니다.
